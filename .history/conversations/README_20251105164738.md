# Copilot Conversation Recordings

This folder contains recordings of GitHub Copilot chat conversations during lab exercises. These recordings are used to:

- **Track learning progress** - See how developers use Copilot to solve problems
- **Improve Copilot usage** - Identify patterns and best practices
- **Grade lab completion** - Assess both outcomes and the process of getting there
- **Provide feedback** - Offer personalized suggestions for better Copilot usage

## File Naming Convention

Conversation files follow this naming pattern:
```
YYYY-MM-DD_HHMMSS_<username>_lab-<number>.md
```

Example: `2025-11-05_143022_john-doe_lab-3.md`

## File Structure

Each conversation file contains:

1. **Metadata** - User, lab, timestamps, model info
2. **Conversation History** - Full chat transcript with prompts and responses
3. **Tool Usage Analytics** - What tools were called and why
4. **Token Usage Summary** - Running count of tokens consumed
5. **Context Annotations** - What files/context were added to prompts
6. **Summary** - Key actions taken and outcomes achieved

## Automatic Recording

Conversations are automatically recorded when you use GitHub Copilot Chat. The recording system:

- Creates a new file for each chat session
- Appends to the file as the conversation progresses
- Tracks all prompts, responses, and tool calls
- Records context (files, selections, errors) added to prompts
- Captures mode switches (Ask → Edit → Agent)
- Summarizes token usage throughout the session

## Privacy Note

These recordings help improve your learning experience. They are reviewed as part of the lab grading process. Only conversation content related to the lab exercises is recorded.

## Do Not Edit

These files are automatically generated. Manual edits may interfere with the grading workflow.
