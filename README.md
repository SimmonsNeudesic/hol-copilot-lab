# GitHub Copilot Hands-On Labs 🚀

## Welcome to The Daily Harvest Development Experience!

This comprehensive hands-on lab series is designed to transform you into a GitHub Copilot power user. Through practical, real-world scenarios at **The Daily Harvest** - a fictional e-commerce startup - you'll master AI-assisted development from code understanding to autonomous coding.

## 🍎 About The Daily Harvest

You've just joined The Daily Harvest, an innovative startup revolutionizing fresh fruit sales through e-commerce. As a new developer, you'll use GitHub Copilot to accelerate your productivity while maintaining high code quality and security standards.

## 📚 Lab Series Overview

### Lab 1: Understanding Your Project (30 minutes)
**Start Here!** Learn to use GitHub Copilot Chat to rapidly understand unfamiliar codebases.
- Explore project structure and purpose
- Identify technologies and dependencies
- Learn build and test processes
- **Outcome**: Enhanced README documentation

### Lab 2: Completing Features with Copilot (30 minutes)
Experience real-world feature development using GitHub Copilot.
- Work from a pre-created GitHub issue
- Use inline completions and chat modes
- Write comprehensive unit tests
- **Outcome**: Completed feature implementation

### Lab 3: Achieving Goals with Agent Mode (45 minutes)
Delegate complex, multi-file tasks to GitHub Copilot Agent.
- Set measurable goals (80%+ test coverage)
- Watch autonomous multi-file changes
- Understand agent decision-making
- **Outcome**: Comprehensive test suite

### Lab 4: Autonomous Coding with Coding Agent (45 minutes)
Experience GitHub Copilot as a team member working independently.
- Assign GitHub issues to Copilot
- Monitor autonomous development
- Review and iterate on AI-generated PRs
- **Outcome**: Production-ready features

### Lab 5: Extending Capabilities with MCP (30 minutes)
Connect external services and knowledge to GitHub Copilot.
- Set up Model Context Protocol servers
- Integrate GitHub and documentation
- Reduce context switching
- **Outcome**: Enhanced development workflow

### Lab 6: Customizing Copilot Behavior (30 minutes)
Tailor GitHub Copilot to your organization's standards.
- Create custom instructions
- Build reusable prompt files
- Design custom chat modes
- **Outcome**: Personalized AI assistant

## ⚡ Quick Start

### Prerequisites
Before starting, ensure you have:
- ✅ GitHub account with Copilot access
- ✅ Visual Studio Code installed
- ✅ GitHub Copilot extension installed
- ✅ Node.js 18+ installed
- ✅ Git configured

### Getting Started
1. **Clone this repository**
   ```bash
   git clone https://github.com/YourOrg/hol-copilot-lab.git
   cd hol-copilot-lab
   ```

2. **Start with Lab 1**
   - Navigate to `Instructions/Labs/Lab-1-Understanding-Project.md`
   - Follow the step-by-step instructions
   - Complete each checkpoint before moving on

3. **Progress through labs sequentially**
   - Each lab builds on previous knowledge
   - Use prestaged branches when available
   - Take time to experiment and explore
